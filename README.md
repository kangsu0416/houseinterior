# 목감 퍼스트리움 85A1 가구 배치 플래너

목감 퍼스트리움 85A1 타입에서 후보 가구의 평면상 배치 가능성을 확인하는 모바일 대응 웹 앱입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

Cloudflare Pages 설정:

- Framework preset: `Vite`
- Build command: `npm run build`
- Build output directory: `dist`
- Node.js: 20 이상

## 주의

내장 평면도는 구조 검토용 참고 도면입니다. 실제 구매 전 설치 위치, 반입 경로, 문폭, 엘리베이터, 몰딩 등을 직접 실측해야 합니다.
