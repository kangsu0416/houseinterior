# 목감 퍼스트리움 85A1 가구 배치 플래너

목감 퍼스트리움 85A1 타입에서 후보 가구의 평면상 배치 가능성을 확인하는 모바일 대응 웹 앱입니다. 공개된 1407동 59.80A1 실세대 사전점검 자료를 바탕으로 방·주방·욕실·현관·발코니 구조와 기본 붙박이장·ㄱ자 싱크대를 반영했습니다.

가구가 벽, 다른 가구, 고정 설비뿐 아니라 현관·중앙 연결부·거실·주방·침실 출입 통로를 막는지도 함께 검사합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

Cloudflare Pages 설정:

- Framework preset: `Vite`
- Build command: `npm run build`
- Build output directory: `dist`
- Node.js: 20 이상

## 주의

공개 자료는 방문한 정확한 호수를 밝히지 않으므로 1407동 1호 라인의 좌우 방향은 확정하지 않았습니다. 내장 평면도와 통로 폭은 구조 검토용 참고값이며, 실제 구매 전 설치 위치, 반입 경로, 문폭, 엘리베이터, 몰딩 등을 직접 실측해야 합니다.
